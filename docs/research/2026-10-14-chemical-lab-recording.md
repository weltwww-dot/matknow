# 化学与材料制备：实验记录和报告的最小依据

核查日期：2026-10-14。用途：为现有桌面应用的实验记录、报告整理与导出提供依据；不是合成方案、实验安全操作规程或合规认证。仅核查下列机构第一方 HTML 页面。高校旧课程页面用于说明记录原则，不作为当前安全规范；期刊投稿要求也不等同于所有实验室的强制标准。

## 1. 证据支持的记录原则

- **记录实际发生的事情，并及时记录。** UCLA 研究组要求每日记录、逐步记录加料顺序/时间/温度；MIT 化学课程要求直接记录数据、附单位，按发生顺序记录实际操作和观察。实验计划或讲义不能替代事实记录。[UCLA：Notebooks & Research](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html)、[MIT：5.310 Notebooks](https://www.mit.edu/course/5/5.310/OldFiles/wwwtest/general_info.html)
- **原始记录与事后报告职责不同。** 原始记录保留操作、观察和数据；报告用这些记录形成可读的结果与讨论、结论和实验部分。报告应可回指所覆盖的记录。[UCLA：Research Reports](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html)
- **数量与样品必须能追溯。** 原料来源/等级、称量或体积与浓度、实际操作参数、样品送测和相关记录需要交叉引用；商品材料批次有助于追溯。[MIT：5.310 What to Record](https://www.mit.edu/course/5/5.310/OldFiles/wwwtest/general_info.html)、[MIT：10.27 Notebook Appendix II](https://web.mit.edu/10.27/www/1027CourseManual/1027CourseManual-AppII.html)
- **异常和中止也属于记录。** UCLA 要求记载中止时间和原因；MIT 要求原始条目更正后仍可读，不擦除原值。好看的报告不能倒过来覆盖原始记录。[UCLA：Laboratory Notebooks](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html)、[MIT：Notebook Appendix II](https://web.mit.edu/10.27/www/1027CourseManual/1027CourseManual-AppII.html)
- **报告须足以复现，并说明计算依据。** RSC 要求试剂/产品/溶剂用量、时间/温度、纯化和产率算法；测量精度、不确定度和有效数字应与证据相符，特殊危险应说明。[RSC：General guidance / Synthetic procedures](https://www.rsc.org/publishing/publish-with-us/publish-a-journal-article/experimental-reporting)
- **表征结论需要真实数据。** ACS 要求保留原始数据，缺测应说明原因；NMR 原始文件包括 FID、采集及处理参数，不能隐藏杂质峰。材料测试还应记录样品制备历史和测量条件。[ACS：Research Data Guidelines](https://researcher-resources.acs.org/publish/data_guidelines)
- **鉴定、纯度和整体均一性不能混为一谈。** RSC 指出准确分子质量不能单独证明纯度，单晶结构也不能单独证明块体结构；表征证据随材料种类选择。[RSC：Characterisation / Inorganic compounds](https://www.rsc.org/publishing/publish-with-us/publish-a-journal-article/experimental-reporting)

## 2. 适用于本产品的最小字段（设计推论）

下表是上述原则在材料制备助手中的适配，**不是来源声称的统一数据库标准，也不是要求本轮全部开发**。优先复用已有字段、自由文本和附件；未知允许留空并显示“未记录/待补充”。适用性不同的项目不能一概设为必填。

| 记录对象 | 建议保存的信息 | 推论依据 |
| --- | --- | --- |
| 实验身份 | 编号、标题、目的、操作者、实际日期；补录时分别保留发生时间和录入时间 | [MIT 记录身份与时序](https://www.mit.edu/course/5/5.310/OldFiles/wwwtest/general_info.html) |
| 方法来源 | 文献/既有 SOP/已有实验编号，版本或可定位的出处；标明“计划/参考” | [UCLA 方法与相关实验索引](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html) |
| 原料与溶液 | 名称/配方、供应商与批次（已知时）、等级或纯度及其来源；实际质量/体积和单位、浓度和浓度基准、必要的物质的量 | [MIT 原料来源与批次](https://web.mit.edu/10.27/www/1027CourseManual/1027CourseManual-AppII.html) |
| 实际过程 | 按序号/时间记录操作、加料顺序、条件；观察、相对计划的偏差及原因；中止状态 | [UCLA 逐步记录](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html) |
| 材料条件 | 按需记录容器/仪器、温度与时间、升降温过程、气氛/压力、搅拌/流量、洗涤/分离/干燥及后处理；区分设定值和实测值 | [MIT 操作条件](https://web.mit.edu/10.27/www/1027CourseManual/1027CourseManual-AppII.html)、[ACS 样品热/压/气氛历史](https://researcher-resources.acs.org/publish/data_guidelines) |
| 产物与样品 | 样品/批次号、父实验/分样关系、外观、实际获得量；粗品/纯化品/分析产率类型及计算依据 | [UCLA 产物与谱图交叉引用](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html) |
| 表征与附件 | 方法、样品号、测量日期、仪器/条件、原始文件位置与说明、处理结果；测量值/单位、重复数和不确定度类型（已知时） | [ACS 原始数据与测试条件](https://researcher-resources.acs.org/publish/data_guidelines) |
| 更正 | 原值、改后值、理由、作者和时间；报告引用具体记录版本 | [MIT 保留可读原值](https://web.mit.edu/10.27/www/1027CourseManual/1027CourseManual-AppII.html)；电子版本映射为本产品推论 |

## 3. 表征元数据按方法选择（设计推论）

不要强制所有实验同时填写 NMR、XRD、SEM 等表格。允许用“方法 + 条件说明 + 结果 + 原始附件”承载以下信息，后续按实际需求结构化。

- NMR：核种、频率、溶剂/参考、真实谱图及原始数据；PXRD：仪器、波长、测试温度，精修时增加步长与拟合信息。[RSC：NMR / X-Ray crystallography](https://www.rsc.org/publishing/publish-with-us/publish-a-journal-article/experimental-reporting)
- 材料力学/热机械测试：仪器、试样形状尺寸、制样和预处理、温度/气氛、速度或扫描条件；汇总时保留样本数及统计量定义。[ACS：Polymer Science Data](https://researcher-resources.acs.org/publish/data_guidelines)
- 本产品推论：显微图等附件须绑定具体样品和实验，记录采集条件；只有图像文件名不能证明其测量对象。上传文件可作为证据附件，但不能据此自动宣称已完成解析、物相识别或纯度判定。

## 4. 报告章节与生成边界（设计推论）

建议沿用现有报告输出，并组织为：基本信息与目的 → 方法来源 → 原料和设备 → 实际操作与条件 → 观察及偏差 → 产物/样品与表征 → 结果和计算 → 讨论与局限 → 结论 → 原始附件与参考来源。此结构综合 UCLA 的研究报告分工和 MIT 的事实记录要求，不代表必须使用同一格式。[UCLA 报告结构](https://www.chem.ucla.edu/research/org/merlic_group/Notebooks_and_Research.html)、[MIT 事实记录](https://www.mit.edu/course/5/5.310/OldFiles/wwwtest/general_info.html)

产品应明确区分“用户记录”“文件证据”“引用文献”“程序计算”和“分析建议”。AI 可以整理措辞、指出缺项、形成带出处的解释；不得自动补造实际称量、试剂纯度、仪器型号、发生时间、颜色变化、产率、谱峰、物相或成功结论。没有真实测量的实验，输出应叫“实验方案/待补充报告”，不能伪装为已完成实验。以上是对事实记录原则的产品推论。[MIT 客观事实与更正](https://web.mit.edu/10.27/www/1027CourseManual/1027CourseManual-AppII.html)

有明确输入、单位与模型前提时才计算；缺摩尔质量/浓度基准/限量反应物等信息时展示缺项，不猜。无合理反应式或理论产量的材料制备，不强行套用化学反应百分产率。原料供应商标称纯度应与产品实测纯度分开；“未记录”不得变成“无异常”。这些是本产品的准确性约束。

## 5. 可作为本轮或后续验证依据的场景（产品验收推论）

1. **只有文献方案**：提供文献温度和时间，未提供执行记录；导出保留为参考/计划，实际结果写待补充，不生成实测结论。
2. **计划与实际不同**：计划称量 1.00 g、实际 0.98 g；报告保留实际量和偏差说明，不能用计划值覆盖。
3. **跨日补录与中止**：第二天补录前日中止实验；发生日期与录入日期可区分，中止原因与已有观察仍进入报告。
4. **单位或浓度不完整**：写“溶液 5 mL，浓度 10%”而未注明质量/体积基准；保存原文并提示基准待补充，不计算 mmol 或擅自换算。
5. **产率缺依据**：只有获得量 0.20 g，没有反应式/限量物/理论产量；保留质量，不产生百分产率；粗品不能写成纯化分离产率。
6. **多样品及文件关联**：一个批次分成 A/B，只有 A 有表征附件；A 的证据不能支持 B 的相同表征结论，附件可回指样品和原始实验。
7. **缺测与不确定度**：记录单次测量但未提供重复数/误差；不生成标准差、误差条或“高重复性”；没有表征时不称“高纯/目标物相”。
8. **纠错后再导出**：纠正某用量，旧值和更正说明可追溯；新报告使用新值，已有旧报告的来源版本仍可辨识。旧应用未具备版本机制时列为后续能力，不能宣称已合规。

## 6. 本次改进的范围建议与局限

优先解决报告事实与来源可区分、缺项可见、实际操作/观察/偏差可表达、样品与附件可回指这四点。复杂库存、自动仪器接入、完整签名审计或 LIMS 不由本次调研自动授权。不能仅凭本说明宣称软件满足 GLP、GMP、电子签名法规或机构档案要求。

本说明未读取用户实验数据，也未验证任何具体实验结果；领域专属模板仍需结合课题组 SOP 和材料体系。本轮来源为高校课程/研究组指导及 ACS/RSC 投稿指南，证据范围不包含全行业调查。
