# 实验记录

顶部先选择研究方向，再打开“实验记录”。每个方向的实验、附件、历史和模型选择独立。

日常使用只需三步：点击“记实验”写过程，双击记录查看，打开后“添加结果”。首页每次实验只显示一条，多样品不会重复成多行。名称、日期、目的和过程直接填写；“实验详情”按需展开。

## 化学实验怎样记录

过程按时间顺序记录实际操作、条件和观察，注明与计划不同之处；中止的实验保留时间和原因。计划、实际观察、对原因的解释分别保存，不用预期结果替代实测结果。

“实验详情”可补充试剂名称、实际用量和单位、规格/浓度、来源/批号，及其对应的样品编号；样品栏留空表示共用。另可填写操作者、状态、装置、偏差、参考方法及分析总结。实际用量允许原样文字，不自动换算单位或推算产率。快速记录时缺项不阻止保存，生成报告时提示核对。修改样品编号后，也需核对试剂表中的关联编号。

这里的记录原则来自 UCLA/MIT 实验记录指导与 ACS/RSC 报告要求，具体来源及适用范围见 [调研记录](research/2026-10-14-chemical-lab-recording.md)。

## 导入和录入

**连接模型时：** 导入 `.docx/.xlsx` 后自动整理，先显示名称、状态、目的、样品、材料、结果数量和待核对项。模型识别样品、条件、试剂与操作，原文及字段定位保留在记录中；点击“编辑详情”修改，勾选核对后保存。“重新用模型整理”会替换当前未保存的整理草稿。原文没写的日期暂用录入日期并提示核对，其他缺项不猜测。

模型可根据当前提供的最近20条实验推荐保存位置；关联不唯一时默认新建。确认关联后追加为该实验的新版本，保留原样品、结果和历史。条件和试剂冲突时停止合并，请核对或选择新建；原文件的不同工作表/范围可分别追加，同样品同指标同来源定位的重复测量会拦截。文件关联前没有写入实验档案。

方案自动标记计划中，计划测试和预期结果保留在原记录，不进入实测结果。方案不能把已有执行状态或实测结果退回计划。Excel 默认读取支持范围内的工作簿；超过20个工作表或50000单元格时回到范围选择，之后继续模型整理。原文超过模型上下文时需在“原文 / 手动整理”缩小选择，不静默忽略内容。

**未连接模型或需要手动整理时：** 使用“原文 / 手动整理”入口，按以下步骤操作。

1. 点击“导入”，选择 `.docx` 或 `.xlsx`。Excel 可先选择工作表和读取范围，范围按“起始行,起始列,结束行,结束列”填写。
2. Excel 按列指定样品编号、制备条件和数值结果；填写指标与单位，选择表头行和结束行。重复编号默认要求修正，确为同一样品多次测试时，选择“同一样品多次测量”。Word 可手动填写 `A1,A2,A3` 等样品编号，选择原文生成草稿。
3. 在“核对草稿”中修改实验名称、日期、共用条件、样品条件与实验记录。样品条件覆盖同名共用条件。点击“编辑结果”补充结果。已配置模型时，可用“用模型整理所选原文”生成候选字段，仍需核对。
4. 核对后勾选确认并保存。公式显示表达式及文件内已有缓存，不重新计算；没有缓存的数值必须手动补充或改为文字/移除。未确认草稿不进入档案、检索或对比。

点击“记实验”可手动录入，无需 Key。双击记录打开后，点击“编辑记录”修改。导入含结构化条件或多个样品的草稿时，会展开样品区域供核对。原始文件会复制到当前方向的存储目录，之后移动用户原文件不影响档案。

## 添加结果

打开一条实验记录，在顶部选择样品，再点击“添加结果”。默认填写指标、数值或观察、单位和类型；测试方法、条件、时间及曲线设置通过“测试信息与文件设置”展开。每个样品可添加多条数值、文字观察或附件结果，同指标的新测量保留为独立行。

- CSV / XLSX：查看分页数据，在“表格 / 曲线”指定工作表、数据范围、X/Y 列和单位，再预览曲线。也可填写 `B2` 等单元格，将其取为可对比的数值，保留来源定位。
- PNG / JPEG：查看缩略图，不自动解读图片内容。
- PDF：展示可提取文字及页码；扫描件或无法解析的 PDF 保留原件。
- 其他仪器文件：保留原始字节，可另存为，不自动运行或调用外部程序。

结果保存后，记录窗口的“结果”中选择具体结果，在“文件”中点击原件查看。添加时的“查看文件”可预览当前已关联文件。附件读取失败不会抹去原件。

小窗口中点击“放大预览”可完整查看图表、图片或报告；空间不足时不会把坐标挤在一起。

曲线仅用于查看：不拟合、不找峰、不做自动材料表征。空白或无效值形成缺口，不填零。按 X 排序只在勾选后生效，缺口两侧仍分开绘制。显示最多 2000 个抽样点并保留区段极值，导出的原始数据不减少。

## 样品对比和实验问答

连续点击实验记录可多选用于问答，每条默认包含该实验的全部样品；再次点击取消。“更多 → 选择样品”可精确选择当前记录页中的某几个样品，已有其他页的选择会保留。可以跨实验比较同名样品，它们仍是不同的样品记录。

选择 2–20 个样品，点击“更多 → 对比所选样品”：

1. 条件表标明相同、不同或缺失；未记录条件不等同于相同条件。
2. 按指标、单位、方法与测试条件分组。未知测试条件标为“待核对”。
3. 在某组中明确选择要排序的测量，点击“从大到小”或“从小到大”；选定参照测量后可查看差值。程序使用原始十进制数值计算，不自动取最新值、求平均或选择代表测量。
4. 确属等价写法的测试组可人工确认映射，只影响本次比较；不修改原始值，也不换算单位。

资料和实验共用中央聊天框、模型选择和历史。选好样品后直接在中央提问；可在对比窗口中向完整已选范围提问，回答也进入中央聊天区，并保留本次人工确认与计算。没有 Key 时仍能查看完整比较与本地证据。普通问题先检索相关资料与实验片段，智能体可继续读取和对比；排名、计数等问题须先明确完整范围。内容超过模型上下文限制时要求缩小范围，不丢掉样品后继续计算。

数值较高是否更好取决于研究目标；条件差异不能证明唯一因果。模型回答的引用须能对应本次记录，但引用格式正确不代表科学结论正确，仍需核对原文。

## 保存、删除和导出

每次保存生成新版本。新查询使用当前版本，历史引用保留原版本的值并提示“记录已更新”。从当前版本移除样品/结果后，旧版本和共用原件仍保留。

旧实验可继续打开；新增化学详情默认为空。首次打开旧数据库时将实验格式标记升级到 2，不改写历史记录内容。为避免新字段被旧版编辑器丢弃，升级后的数据库不再交给 v0.7.x 写入；需要回退时使用升级前另存的完整数据目录副本。

### 生成实验报告

打开记录点击“生成报告”，或“更多 → 生成当前实验报告”。预览后可导出 `.docx` 或 `.md`，无需 Key。报告包含目的、方法依据、试剂、装置与条件、操作观察、偏差、各样品结果、用户填写的讨论结论、原件关联及待核对项。原始有效位数、单位、重复测量逐条保留；人工修正的条件保留修正标记，曲线保留所选文件、工作表、列和范围信息。

报告为草稿：未记录的字段标为“未记录”，不自动补全产率、误差、峰归属或成功结论。原件核验仅检查文件存在且字节与保存时一致，不证明数据或解释科学上正确。结果图片和曲线不直接嵌入报告，原件仍在“文件”中查看。

连接模型时自动生成独立的“AI 分析草稿”，列出依据章节、分析局限、建议和不确定事项；不会改写原始记录或用户结论。失败时原报告仍可导出，预览中可“重新生成 AI 分析”。计划中的试剂量标为计划用量，其余用量为记录用量，状态未知时不声称实际执行。

从历史引用打开记录后，“生成报告”使用窗口显示的历史版本；“更多”入口使用当前选中实验的最新版本。一次生成一条实验的报告，包含该版本全部样品，不把多个实验悄悄合并。导出报告仅包含记录内容和原件名称，不附带知识库数据库、Key 或自动写入本地文件路径。用户自己录入的敏感文字仍会原样导出，请在分享前核对。

点击多条记录选中后，点击列表下方的“删除所选”，或“更多 → 删除所选实验”。支持跨页选择；没有选择时不会自动删除焦点所在的记录。确认框列出实验名称、日期和样品数，较多条目可展开详细信息，默认取消。删除单位是整条实验，即使问答范围只选择其中部分样品，也会在确认后删除该实验的全部样品、版本和附件副本。

删除后历史来源失效，已生成的历史回答正文可能包含旧值，不会随来源自动抹除。若部分删除失败，界面显示实际成功和失败数量，失败记录保留选择便于重试。数据库中断导致无法确认状态的记录会单独标记，不计入明确成功或失败。若附件被占用，应用保留清理队列并在下一次启动重试；不会误报物理文件已删。用户导入前的原始文件保留。

可导出样品对比 Markdown、带版本引用的实验问答 Markdown，以及结构化实验档案 ZIP。实验包包含选定版本的结构化记录和关联原件，不含应用 Key 或原始文件的磁盘路径。导出用于保存和共享，首版没有实验包自动导入功能。历史版本可通过核心导出接口指定；桌面“更多”导出当前版本。

## 模型生成完整报告

在聊天框选择厂商与模型后，打开实验详情点击“生成报告”，或选择实验后使用“更多 → 生成当前实验的完整报告”。模型依据指定版本的全部样品、共用条件、试剂用量、操作观察、每次重复测量及可读取关联原件，撰写七个章节，再单独检查遗漏、数值单位、来源、计划与实际、假设与结论。界面显示撰写和复核阶段，正常调用两次外部模型；结构不合规时每步最多重试一次。

模型正文注明依据，逐条原始记录对照保留在后；可导出 Word / Markdown，不修改实验档案。附件可能包含其他批次，模型仅将明确对应当前记录的内容用于解释；图片内容不自动解读、公式不自动重算。未读取内容及缺项明确列出。模型复核仅检查本次来源的一致性，仍需核对原件及科学判断。

未设置模型、生成或复核失败时只显示“原始记录整理稿”，并提示原因。重新生成始终使用最初指定版本，不把上次 AI 正文当成原始证据。旧默认实验规则升级时更新；用户改过的规则保留，需包含 experiment_agent.md 中的 write_report/review_report 协议。

“更多”菜单名称直接说明功能和范围，不再附加省略号。选择样品用于问答与对比，删除仍以整条实验为单位。

## 文件限制

单文件 20 MB，提取文本 100 万字符，PDF 100 页。DOCX/XLSX 解压总量 100 MB、5000 个成员；Excel 单次最多 20 张工作表、50000 个所选单元格。桌面逐工作表导入，列映射范围最多 100 列。CSV 最多 50000 行、100 列和 100 万单元格。图片最多 1600 万像素。

旧 `.doc/.xls`、宏文件不支持，请另存为 `.docx/.xlsx`。不执行公式、宏或外部链接。DOCX 嵌入图片与修订痕迹不作为已准确解析的字段，复杂版式需核对。没有解析的仪器文件只保存原件。

本轮测试使用虚构记录、临时方向和受控模型响应。尚未验证你的真实 Word/Excel 版式与付费模型效果。建议提供脱敏的制备记录和对应测试数据，各含多样品及重复测量，作为实际使用验收样例。
