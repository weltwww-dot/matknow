# 科研任务智能体

“对话”页连续显示多轮消息，用户消息靠右，回答加粗。“新对话”开启独立上下文，旧会话保留在“历史对话”中；双击历史项恢复全部消息并继续聊，关闭应用后也可恢复。历史仅显示标题，不显示轮数；模型在正常分流请求中概括标题，没有有效标题时暂用首条问题。右键选择“重命名”可填写1–50字符的单行标题，修改后持久保存并禁止模型覆盖。旧版单条问答各自保留为独立对话。会话按研究方向隔离，存储于该方向的本地数据库。

每次请求以user/assistant消息发送当前会话问答。上下文按所选模型实际窗口扣除输出预留后管理，不设固定字符上限或容量百分比上限；接近可用输入容量时整理较早对话，近期完整消息和原始历史保留。模型容量优先取厂商模型列表的context_length/context_window及top_provider.context_length，冲突取较小值；其他接口不根据同名模型猜容量。容量未知时完整发送当前上下文，由模型服务判定，接口报超限后再压缩历史并最多重试一次。

输入框右下角圆环显示上下文占用，悬停查看token用量、模型容量、估算/厂商返回标记与自动压缩说明。输入时显示当前背景加草稿的估算，不含尚未检索的证据；实际请求时包含系统指令和已检索证据，接口返回usage后更新为输入加输出token。厂商未提供容量时显示未知，不给出虚构百分比。估算使用轻量文本启发式，不等于厂商精确分词；输出预留与自动压缩阈值会使可用输入小于总窗口。

较早内容由当前模型分段摘要，成功后保存复用；摘要和原文都发给所选厂商，会计入用量，首次整理会增加摘要请求。摘要失败不覆盖已有检查点，也不省略旧内容后继续回答。新对话、研究方向和读取范围隔离；重开历史恢复仍有效的选择，原范围全部失效时要求重新选择，不自动扩大到全库。科研追问重新检索来源，删除引用来源后排除受影响回答，仍保留原用户问题和无关聊天背景。摘要按会话、范围和原历史指纹保存，重启或切换大容量模型仍可复用；容量错误只在实际缩短后重试一次，鉴权和网络错误不按此方式重试。

选择研究方向并配置模型后，在统一聊天框提问。左侧“资料库”和“实验记录”用于管理，切换不影响聊天。选中的资料与样品同时限定对应工具；某类没有选择时使用当前方向该类全部记录。需要比较实验时先选中相关样品，问题中写清指标和目标。

桌面会自动分流：问候、模型身份、通用知识或写作直接普通回答，不加载 `agent.md`、不读取知识库片段；需要使用本地资料或实验功能时才进入科研流程。例如“什么是XRD”可普通回答，“从导入的论文解释XRD结果”则检索资料。普通聊天不要求本地引用，也不显示科研处理步骤。没有连接模型时保留本地检索预览。

可尝试：

- “从资料中整理溶剂置换步骤，给出原文出处。”
- “比较所选样品的强度与制备条件，哪些测试条件还没记录？”
- “以 A1 的这次测量为参照，比较同测试组的强度差值。”
- “文献里的干燥条件与这批实验有什么区别？哪些解释还缺证据？”

智能体先形成行动计划，再调用本地工具：检索或读取资料、读取授权文件、查找或对比样品、准备实验草稿。工具返回实际结果后，智能体决定继续查找或回答。工具请求经过白名单、参数及所选范围校验，计算使用现有样品比较程序。

资料库和实验智能体共用 `read_file`。聊天里给出完整本地路径后，可读取、调用当前模型分段整理类别/摘要/标签，并导入当前方向资料库。ZIP不落盘解压，按has_more和next_offset处理到末页；仅附少量预览证据，全文保存在库内，可用read_documents分页读取。原件归属和全部来源关联保留，成功分段与最终整理结果支持续接和复用。当前对话同范围的用户路径授权独立于有界模型历史，失败或较早轮次仍可续接；新对话、其他方向或范围不能继承。

v0.10.12起也可直接提供本地文件夹，包含无扩展名、空格及中文目录。工具递归读取其中支持的文档，按has_more和next_page分批处理，保留相对文件名与论文分组。可读取授权目录内的具体文件，不可扩大到父目录或同级文件；应用内部存储与链接路径跳过。最多500个目录条目、100 MB，每批最多10份。原文件和目录结构不修改，任务中目录成员变更或已读原文变化会阻止当前结论。

目录工具按编号、成员路径或主题查找；document_catalog保留本题已查到的编号，catalog_pages保留分页位置，next_page提供保持原查询的下一页参数。来源正文和资料编号分别标明，避免混用。回答只显示紧凑引用，点击后在来源面板查看完整原文。

实验/联合任务通过prepare_experiment_draft生成方案、记录或结果候选；由聊天入口打开原有核对窗口，用户确认后才写入实验记录。草稿来源限于当前选择，保存附所选文字快照，计划不产生实测。保存失败可重试，已保存草稿不会重复写入。

状态栏显示当前阶段，回答末尾显示简短处理步骤。任务完成或停止后，答案、计划和工具摘要一起保存在本方向历史中，导出时保留摘要；不记录模型隐藏推理。

数量和排名必须对应完整选择或已确认完整的样品列表，不能用几段搜索结果充当全库统计。排名需有同组数值计算并引用该计算的测量；统计全部测量不能用单一指标的计数代替。工具不擅自合并单位、确认测试等价关系或挑选重复测量。图片及未解析附件只知道存在。

普通聊天一次模型请求完成；科研任务在一次分流后，默认最多6轮工具循环模型请求、48个证据片段。工具结果有独立边界，上下文容量由当前模型决定。规则来自项目根目录（安装版 EXE 同目录）的 `agent.md`，每次科研任务重新读取，修改后下次生效。保留“运行参数”JSON及“系统指令”标题；错误、缺失或超限规则会停止科研执行，不影响普通聊天。升级保留已编辑的规则文件。工具执行及范围、引用和计算校验由 Python 强制执行。

超过范围、数据更新、模型失败、引用校验失败时会说明未完成或需要补充，而不会把未验证草稿当成完成结果。引用检查证明来源和编号对应，不能自动证明所有科研推断；因果解释与实验决策仍需核对原文。

工具读取当前方向资料和实验记录，以及用户明确给出的 file_paths。读取原件只读；read_file可将解析原文与模型候选写入当前方向资料库，不写原文件、不执行系统命令、不读取应用API Key、未授权路径、其他方向数据或外网论文。问题、有界会话上下文、方向说明、相关证据及工具观察发给所选模型；文件分类还会发送该文档的解析原文。超过上下文时不省略后冒充完整整理，分类失败保留原文。
