# 请帮「材知」收集这些资料

这批资料用于知识库检索与答案核对，首版不需要训练模型。先围绕你最熟悉的一个材料体系收集，例如同一类薄膜、凝胶或颗粒；尽量不要首批就混入多个不相关体系。

## 第一批：有这些就可以开始

| 优先级 | 资料 | 建议数量 | 具体要求 | 用途 |
| --- | --- | --- | --- | --- |
| 必需 | 材料制备论文全文 | 5–10 篇 | 有完整方法部分、文字可选中的 PDF，优先公开可使用版本；围绕同一材料体系 | 回答原料、步骤和文献报告的条件 |
| 必需 | 上述论文的补充材料 SI | 每篇尽量配齐 | 与正文一一对应，保留原文件与 DOI／论文标题；找不到就记录“未找到” | 找正文略写的设备、过程和参数 |
| 必需 | 人工核对问答 | 第一批 20–30 题 | 每题写问题、标准答案要点、来源文件、页码或章节、支持答案的短原文 | 检查回答是否真的有依据 |
| 推荐 | 实验室 SOP／操作规范 | 2–3 份 | 使用你有权用于项目的版本；标注版本日期和适用材料／步骤 | 覆盖实验室实际表达和常见问题 |
| 推荐 | 设备说明书相关章节 | 1–2 份 | 明确厂商、型号、版本，只需与制备相关章节 | 回答说明书明确记载的设备条件与术语 |

没有 SOP 也能先做。论文全文和 SI 最有价值，只有摘要不足以覆盖制备方法。

## 每篇论文请一起记录

- 自定资料编号：例如 P001；对应 SI 为 P001-SI。
- 完整标题、DOI 或官方来源链接、年份。
- 材料体系和样品编号；论文涉及多个样品时列出你关注的一个。
- 正文／补充材料／SOP／说明书类别。
- 文件名和语言；记录 PDF 中 Methods/Experimental 的物理页码。
- 资料用途：仅内部调试、可公开演示、或可随项目分发；不确定时标记待核实。
- SI 与正文的对应关系；SOP 和设备说明书的版本信息。

可使用 `data/collection-template.json` 记录这些信息。导入前建议给文件名加资料编号，例如 `P001-paper.pdf`、`P001-SI.pdf`，避免不同论文都叫 `paper.pdf` 而无法区分。原始标题仍记录在元数据里。首版暂不自动读取元数据 JSON，它用于资料交接和人工核对；检索范围在桌面列表中选择。

## 问答题怎么准备

建议第一批按下面比例覆盖，不要求所有问题都有答案：

| 题型 | 建议数量 | 示例问法 |
| --- | --- | --- |
| 单文件事实 | 8 | “P001 中样品 A 的干燥时间是多少？” |
| 正文＋SI 联查 | 5 | “正文提到的预处理，在 SI 哪里有详细描述？” |
| 方法对比 | 4 | “P001 和 P002 对各自样品的干燥条件分别怎么写？” |
| 资料未报告 | 4 | “当前资料有没有报告这一步的升温速率？” |
| 信息不足需追问 | 3 | “这个温度是多少？”——缺少论文、样品或步骤，需要先问清楚 |
| 中英文同义问法 | 3 | 同一事实分别用中文和英文提问，核对是否找到相同来源 |
| 不应回答的扩展 | 3 | “把两篇配方拼起来，给我一个保证成功的新配方。”——不应编造保证或未经验证条件 |

每题记录如下字段，可用 `data/evaluation-template.json` 填写：

```text
问题编号：Q001
问题：P001 中样品 A 的干燥时间是多少？
允许检索的资料：P001、P001-SI
预期行为：基于证据回答／说明未找到／先追问
答案要点：由你核对后填写，不要让模型自己编标准答案
依据：文件名＋PDF 物理页码＋章节＋短原文
容易答错的地方：例如样品 A 与 B 条件不同、℃ 与 K 混淆
```

对于“未报告”题，记录你检查过哪些正文和 SI，预期表述限定为“在这些资料中未找到”。引用编号正确不等于答案正确，核对时还要检查样品、步骤、数字和单位是否对应。

## 放到哪里

将找到的文件放入项目目录的 `data/inbox/`。建议整理成：

```text
data/inbox/
  P001/
    P001-paper.pdf
    P001-SI.pdf
    metadata.json
  P002/
    P002-paper.pdf
    metadata.json
  SOP001/
    SOP001-procedure.pdf
    metadata.json
  evaluation.json
```

`data/inbox/` 默认被 Git 忽略，避免论文原件或实验室资料误入公开源码。公开演示时，另外筛选可公开使用的资料；未发表结果、个人信息和账号凭据不要混在知识库里。

## 先不用找

大规模预训练语料、完整实验仪器原始文件、只有图片的扫描 PDF、与所选材料体系无关的大批论文，均不属于首批必需资料。本轮框架使用 `examples/` 下明确标注的教学样例，真实资料到位后再评估检索和模型问答效果。
