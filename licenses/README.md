# 第三方开源许可文本

本目录提供桌面运行依赖的开源许可正文，构建脚本将其合并到发布包的 THIRD_PARTY_NOTICES.txt，并继续收集安装包中提供的通知。

- LGPL-3.0-only.txt：[Qt 官方源码收录的 LGPL v3 正文](https://code.qt.io/cgit/qt/qtbase.git/plain/LICENSES/LGPL-3.0-only.txt)。
- GPL-3.0-only.txt：[Qt 官方源码收录的 GPL v3 正文](https://code.qt.io/cgit/qt/qtbase.git/plain/LICENSES/GPL-3.0-only.txt)。LGPL v3 以 GPL v3 为基础，随附这份文本。
- GPL-2.0-only.txt：[Qt 官方源码收录的 GPL v2 正文](https://code.qt.io/cgit/qt/qtbase.git/plain/LICENSES/GPL-2.0-only.txt)。PySide6/Shiboken 的元数据也列出该许可选项。
- Qt-GPL-exception-1.0.txt：[Qt 官方源码中的异常条款](https://code.qt.io/cgit/qt/qtbase.git/plain/LICENSES/Qt-GPL-exception-1.0.txt)。

Qt for Python 的许可与第三方归属信息见 [官方说明](https://doc.qt.io/qtforpython-6/licenses.html)，源码见 [Qt 源码仓库](https://code.qt.io/)。本项目通过可替换的动态库使用 Qt；构建产物保留相关依赖和通知。Python 和 pypdf 的许可从当前构建环境的发行包收集。
