# 材知 · MATKNOW

面向材料制备、化学实验等科研场景的 Windows 桌面助手，将研究资料、实验记录和模型问答放在同一个工作空间中，帮助整理文献方法、管理样品结果、对照实验条件和生成报告。

## 下载和启动

在 [GitHub Releases](https://github.com/weltwww-dot/matknow/releases/latest) 下载 Windows 10/11 x64 发行版。两种下载方式都包含应用运行所需的依赖。

| 下载项 | 启动方法 |
| --- | --- |
| `MatKnow-0.10.18-Windows-x64-Setup.exe` | 运行安装程序，完成后从开始菜单打开“材知”。 |
| `MatKnow-Windows-x64.zip` | 解压到有写入权限的文件夹，打开其中的 `MatKnow/MatKnow.exe`。保留同目录的 `_internal` 和其他随附文件。 |

全新安装和新解压的免安装版首次启动时，会建立默认的“材料制备”方向。资料库、实验记录、对话和模型设置都是空白。应用默认在程序旁创建 `app-data`，其中保存你的研究方向、资料和记录。需要备份时，先关闭应用，再复制整个 `app-data` 文件夹。

## 快速上手

1. **先选研究方向。** 使用顶部的“研究方向”切换课题，或点击“新建方向”单独管理一个课题。
2. **导入资料。** 打开“资料库 → 导入资料 → 导入文件”，选择文本型 PDF、DOCX、XLSX、TXT 或 Markdown。首次体验可以从仓库的 [examples](examples/) 下载两个 `DEMO-*` 教学文本并导入，也可以通过菜单粘贴自己的文本。
3. **试一次本地检索。** 在资料库选中两份教学样例，在右侧输入“两份资料中的干燥温度和时间分别是多少？”，点击“提问”。查看回答的“出处”，对照输入文字和原文。
4. **录入一条实验。** 打开“实验记录 → 记实验”，填写名称与过程。保存后双击记录，点击“添加结果”。已有 Word 或 Excel 记录可用“实验记录 → 导入”录入，保存前核对草稿。
5. **对比或导出。** 在“实验记录 → 更多”选择样品，执行“对比所选样品的条件和结果”。也可以通过“导出当前实验记录和附件”保存 ZIP 档案。

### 接入自己的模型

1. 点击“模型设置 → 添加厂商”，填写厂商提供的 OpenAI 兼容 API 基础地址和自己的 API Key，例如基础地址 `https://api.example.com/v1`。厂商名称可以自行填写。
2. 点击“测试连接”，然后“保存”。回到聊天区，选择已配置的厂商和该厂商提供的模型。
3. 选中相关资料或样品再提问。要生成实验报告，打开一条实验记录，点击“生成报告”，核对原始记录和报告后导出 Word 或 Markdown。

本地检索、手动记录、附件预览、样品对比和实验档案导出无需 API Key。Key 由应用在本机加密保存。启用模型功能后，相关问题、对话、资料或实验内容可能会发送给你选择的模型服务。分享应用时请使用 Release 下载的干净包。

## 主要功能

### 独立研究方向

为不同课题建立独立研究方向，各自管理资料库、实验记录、附件和聊天历史。在同一应用中切换课题，保留各自的研究背景与模型选择。

### 科研资料库

- 导入文本型 PDF、Word、Excel、TXT 和 Markdown，也可粘贴文本。
- 在聊天中提供文件、文件夹或 ZIP 路径，由模型整理后导入当前方向。
- 自动生成待核对的分类、摘要和标签，保留可读取的原文与来源。
- 多选资料限定检索范围，点击回答中的引用查看对应原文。

### 实验方案与记录整理

- 从 Word、Excel 或资料库原文中提取实验目的、样品、试剂、用量、条件和操作，生成待核对草稿。
- 核对页展示整理内容、共用条件、各样品条件及已有测量，支持编辑后确认保存。
- 同一实验管理多个样品或条件组，可将后续测试结果追加到对应实验。
- 区分实验计划、实际记录和实测结果，保留缺项与来源信息。
- 保存记录版本，追溯实验修改及原始附件。

### 结果管理与样品对比

- 记录数值、文字观察及关联附件，保留每次重复测量。
- 预览图片、可读取的 PDF 文字、表格与曲线，归档仪器原始文件。
- 按指标、单位、测试方法和条件分组比较样品，查看条件差异、数值排序和参照差值。
- 追加导入前查看合并预览，核对新增结果与已有记录。

### 智能体协作问答

资料库智能体负责资料整理与检索，实验智能体负责实验草稿、记录和样品结果。两类智能体共用一个聊天入口，可结合文献方法与本次实验记录处理问题。

- 根据问题规划处理步骤，调用检索、文件读取、实验查询和样品对比工具。
- 普通聊天直接使用所选模型；科研任务结合当前方向和所选资料、样品范围处理。
- 连续多轮对话，支持新建会话、恢复历史和重命名对话。
- 查看处理进度与步骤记录，可停止后续处理。
- 查看上下文用量；上下文上限随所选模型实际容量调整，长对话自动整理较早内容以继续交流。

### 实验报告

根据指定版本的实验记录生成报告，覆盖目的、材料与条件、操作、样品结果、讨论、结论及待补充信息。模型撰写后复核来源一致性，必要时按复核意见修订。

报告保留原始记录对照，可在聊天或实验记录中打开预览，导出 Word 或 Markdown。复核未完成时明确保留原始记录整理稿及待处理问题。

### 自定义厂商与模型

添加厂商名称、API URL 和 API Key，自动获取接口提供的模型列表。在聊天框依次选择厂商及其模型，支持保存多家厂商并切换使用。

应用数据保存在各自应用文件夹中，API Key 在本机加密保存。启用 AI 功能时，相关问题、会话内容、资料或实验记录会发送至所选模型服务。

## 适用场景

- 整理课题文献、实验方法与 SOP，回答带原文出处的问题。
- 从制备方案中提取不同样品的实验条件，减少重复录入。
- 将同批实验的测试结果关联到样品，保留重复测量。
- 对照文献与实际记录，找出缺失信息和需要进一步验证的解释。
- 为日常科研归档与复现整理实验报告。

扫描 PDF 需先进行文字识别。图片和仪器原件可归档，当前不自动解读图像与仪器专有格式。AI 整理、回答和报告均需结合原文及实际实验情况核对。

## 从源码运行和打包

在 Windows x64 上安装 Python 3.11 或更新版本，在项目根目录打开 PowerShell。

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -e ".[dev,build]"
& .\.venv\Scripts\python.exe -m matknow
```

运行测试用 `& .\.venv\Scripts\python.exe -m pytest`。运行 `.\build.ps1` 生成 `dist/MatKnow-Windows-x64.zip`。如已安装 Inno Setup，可在同次构建后运行以下命令生成安装包。

```powershell
& .\.venv\Scripts\python.exe scripts/build_installer.py --compiler "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

安装包输出到 `dist/installer/`。第三方许可说明见 [licenses](licenses/) 和发行包内的 `THIRD_PARTY_NOTICES.txt`。
